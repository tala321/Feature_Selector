دليل الاستخدام

1. رفع البيانات

يمكنك رفع ملف CSV من جهازك أو إدخال رابط مباشر لملف CSV من الإنترنت. تأكدي أن الملف يحتوي على أعمدة منظمة وأن البيانات رقمية.

2. تحديد العمود الهدف

الخوارزميات تفترض أن آخر عمود

3. تشغيل الخوارزميات

  • لتشغيل الخوارزمية الجينية، اضغطي على زر "تشغيل الجينية" بجانب الملف.
  • لتشغيل الطرق التقليدية، اضغطي على زر "تشغيل التقليدية".

4. عرض النتائج

بعد التشغيل، يمكنك معاينة النتائج من خلال صفحات:

  • نتائج الجينية: تعرض الميزات المختارة، الدقة، عدد الأجيال، حجم السكان.
  • نتائج التقليدية: تعرض نتائج SelectKBest، PCA، وRFE.
  • صفحة المقارنة: تعرض مقارنة مباشرة بين الطريقتين.

5. ملاحظات مهمة

  • الخوارزمية الجينية تتعامل مع كل نوع بيانات بشكل مستقل.
  • البيانات النصية غير مدعومة بالكامل حالياً، تأكدي أن البيانات رقمية.
  • الميزات غير المختارة قد تكون غير مؤثرة على دقة التنبؤ، ويمكن عرضها في صفحة الجينية.

6. استخدام Git

يرجى استخدام Git بشكل منظم: رفع الملفات، إنشاء Pull Request، مراجعة الكود، ودمج التعديلات.
